# بوابة التحقق

اختبارات المستودع تغطي تعداد الشاشات الـ92، عزل النطاق والصلاحيات المركبة، إعادة نفس UUID بعد انقطاع التأكيد، إسقاط الأمر المرفوض، الحفاظ على إصدار طلب الاستلام منفصلًا عن حركة الحيازة، مزامنة الملاحظات بعد التأكيد فقط، وحدود تنقل الإشعارات.

اختبارات الواجهة تعرض كل المسارات دون استدعاء إنتاجي أو تغيير بيانات حقيقية، وتلتقط الرئيسية في العربية والإنجليزية بالثيمين بحجم 430×932. هذا فحص عرض وتنقل، وليس إثبات قبول طبي أو محاسبي في الإنتاج.

بعد تثبيت APK بحسابات مفوضة، يُراجع على جهاز حقيقي:

1. دخول وانتهاء جلسة وتجديد وإلغاء جهاز؛ تغيير اللغة والثيم وتكبير الخط.
2. إحالة عميل لطبيب، قبول، سجل AI حتى حد الموافقة، رسالة ومرفق، ملحق سريري، موعد وفحص ووصفة، ثم سحب إسناد.
3. بدء زيارة بـGPS، استكمال تقريرها ثم المهمة؛ حملة ودفعة وحرارة ونتيجة ومراجعة عهدة مستقلة.
4. بيع وشراء بدفعة وصندوق صحيحين، انقطاع أثناء التأكيد ثم إعادة نفس العملية، مرتجع جزئي وتسوية.
5. تحويل واستلام جزئي وجرد، ورفض مصدر أو صندوق خارج التفويض.
6. نقطة استلام وحيازة ورف ورمز سائق، ثم رمز عميل وتحصيل مطابق مرة واحدة فقط.
7. مزاد بأصل وصورة مملوكين، مراجعة مستقلة ثم نشر وفائز وتسليم؛ اقتراح أُعيد للاستكمال ثم اعتماد.

لا تُجري اختبارات Flutter الحالية ترحيل فواتير أو تغيير حالات طلبات حقيقية تلقائيًا.
